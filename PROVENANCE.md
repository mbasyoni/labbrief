# Provenance and candidate status

LabBrief was created on 29 October 2026 as new, independent, AI-assisted utility code for synthetic service intake.

- No private research data, proprietary engines, commercial source code or model weights were imported into this candidate.
- Included requests and model examples are newly authored synthetic data. No experimental validation, battery diagnosis or scientific discovery is claimed.
- Runtime dependencies are Python's standard library, NumPy, scikit-learn and their publicly installed dependencies; the browser UI uses standard browser APIs. No dependency wheels or third-party assets are bundled here.
- PayPal request structures were informed by the official documentation linked in README. Tests use named fake providers, isolated from runtime adapters.
- No credentials, cookies, session capabilities, original private operation fixtures, provider identifiers, raw financial receipts or private runtime state belong in the public candidate.

The accepted private build completed a genuine USD 5.00 PayPal Sandbox capture and browser download on macOS. This candidate is a separate changed tree: private setup/recovery backend and UI surfaces are removed, and the benchmark CLI now handles a clean checkout. Historical private acceptance is recorded evidence, not a real-payment acceptance result for this changed build.

Candidate regression tests, fresh-install results, manifests and source comparison are reported separately. The demo may show actual candidate screens without credentials and a clearly labelled summary of the historical private test. It must not portray that summary as a new live payment.

The MIT license covers this independent source only. No public repository, public deployment or YouTube upload is performed by this package; release remains subject to the owner's review.
